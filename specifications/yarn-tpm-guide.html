How to Specify TPM in a Yarn Requirement

Use this buyer guide when preparing a yarn requirement that includes TPM, or twists per metre.

To specify TPM clearly, share the known twist requirement alongside yarn type, construction, intended application and any reference sample. TPM is a useful input, but it should be reviewed with the other information that defines the yarn brief.

What to include with a TPM requirement

Include the product category, twist direction where known, construction information, intended textile application and a sample reference where available. This gives the TPM request useful context without assuming a fixed value will suit every product or process.
