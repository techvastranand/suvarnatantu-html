Requirement checklist

What should you share for a weaving enquiry?

A complete technical specification is helpful, but an enquiry may begin from partial information and a suitable yarn or fabric reference.

  1. 01

    Fabric / End Product

    What woven textile or finished product is being developed?

  2. 02

    Fabric Construction / Design

    If known, describe the relevant fabric construction, pattern or design.

  3. 03

    Metallic Area

    Where should the metallic effect appear in the woven textile?

  4. 04

    Desired Colour

    Gold, antique gold, silver, copper, custom/reference, etc.

  5. 05

    Visual Direction

    Prominent, subtle, traditional, contemporary or reference-led.

  6. 06

    Existing Yarn Details

    If known: construction/type, denier, twist, TPM or other technical details.

  7. 07

    Warp / Weft Position

    If already known, specify where the yarn is intended to be used. Suitability is not inferred.

  8. 08

    Loom / Process

    Include only if the buyer already knows the relevant process information. Compatibility is not assumed.

  9. 09

    Base Yarn / Fabric Context

    If known, include information about accompanying textile yarns or construction.

  10. 10

    Existing Reference

    Yarn sample, woven fabric swatch, finished fabric, artwork, image, shade reference or technical sheet.

  11. 11

    Approximate Quantity

    Development or bulk requirement.

Weaving application FAQ

Questions for preparing a weaving yarn enquiry.

Do I need to know the exact yarn construction before contacting Suvarnatantu?

No. You can begin with the woven textile, design area, metallic effect, colour direction and available yarn or fabric reference.

What information should I provide for a weaving yarn enquiry?

Share the fabric or end product, design area, metallic effect, colour direction, known yarn information, available reference and approximate quantity.

Can I provide warp or weft information if I already know it?

Yes. If the intended yarn position or fabric construction is already known, include those details as part of the technical brief.

What if I do not know denier or TPM?

Provide the information you already have. Technical variables can be discussed after the application and fabric requirement are clearer.

Do you guarantee compatibility with my loom or weaving process?

Loom and process compatibility should be reviewed against the specific yarn construction, fabric design and operating requirement. Share available loom and process information during technical discussion.

Can I start from an existing woven fabric or yarn sample?

Yes. An existing yarn, woven fabric, image, shade reference or technical specification can help begin the requirement discussion.

Can I request a sample before discussing a bulk order?

Use the Sample Request route to begin sample discussion, then continue toward RFQ once the requirement is better defined.
