Requirement checklist

What should you share for a brocade enquiry?

A full technical specification is helpful, but an enquiry may begin from partial information and a suitable reference.

  1. 01

    Fabric / End Product

    What brocade textile or final product is being developed?

  2. 02

    Pattern Type

    Floral, ornamental, geometric, border, repeat or all-over.

  3. 03

    Metallic Area

    Where metallic yarn appears in the woven design.

  4. 04

    Desired Colour

    Gold, antique gold, silver, copper or custom/reference.

  5. 05

    Visual Direction

    Prominent, subtle, traditional, contemporary or reference-led.

  6. 06

    Existing Yarn Details

    If known: construction/type, denier, twist, TPM or other specification.

  7. 07

    Machine / Process

    Include this only if the relevant setup is already known.

  8. 08

    Existing Reference

    Brocade fabric, yarn sample, pattern artwork, shade reference or technical sheet.

  9. 09

    Approximate Quantity

    Development or bulk requirement.

Brocade application FAQ

Questions for preparing a brocade yarn enquiry.

Do I need to know the exact yarn construction before contacting Suvarnatantu?

No. You can begin with the brocade design, metallic area, colour direction and available fabric or yarn reference.

What information should I share for a brocade metallic-yarn enquiry?

Share the fabric or end product, pattern type, metallic area, colour direction, desired visual effect, known yarn details, reference material and approximate quantity.

Can I start from an existing brocade fabric or yarn sample?

Yes. An existing fabric, yarn, pattern image, shade or technical reference can be used to begin the requirement discussion.

What if I do not know denier or TPM?

Provide the information you already have. Technical variables can be discussed after the application and reference requirement are clearer.

Can I request a sample before discussing a bulk order?

Use the Sample Request route to begin sample discussion, then continue toward RFQ once the requirement is better defined.
