Requirement checklist

What should you share for a jacquard enquiry?

A complete specification is useful, but buyers may begin with partial information and an existing reference.

  1. 01

    Fabric / End Product

    What textile or finished product is being developed?

  2. 02

    Pattern Type

    Motif, repeat, border, geometric, floral, ornamental or all-over.

  3. 03

    Metallic Area

    Where metallic yarn will appear within the pattern.

  4. 04

    Desired Colour

    Gold, silver, antique, copper or custom/reference shade.

  5. 05

    Visual Direction

    Prominent, subtle, traditional, contemporary or reference-led.

  6. 06

    Existing Yarn Details

    If known: type/construction, denier, twist, TPM or other specification.

  7. 07

    Machine / Process

    Include this only if the relevant process details are already known.

  8. 08

    Existing Reference

    Fabric swatch, yarn sample, pattern image, technical sheet or existing construction.

  9. 09

    Approximate Quantity

    Development or bulk requirement.

Jacquard application FAQ

Questions for preparing a jacquard yarn enquiry.

Do I need to know the exact yarn type before contacting Suvarnatantu?

No. You can begin with the jacquard design, colour direction, metallic area and available fabric or yarn reference.

What information is useful for a jacquard metallic-yarn enquiry?

Share the fabric or end product, pattern type, metallic area, colour direction, visual effect, known yarn details, reference material and approximate quantity.

Can I start from an existing jacquard fabric or yarn sample?

Yes. An existing fabric, yarn, pattern image, shade or technical reference can be used to begin the requirement discussion.

What if I do not know denier or TPM?

Provide the information you already have. Technical variables can be discussed after the application and reference requirement are clearer.

Can I request a sample before a bulk order discussion?

Use the Sample Request route to begin the sample discussion, then continue toward RFQ once the requirement is better defined.
