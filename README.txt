SUVARNATANTU — B2B & EXPORT ANIMATED WEBSITE
==============================================

ENTRY FILE
----------
index.html

HOW TO RUN
----------
Option 1 — simplest:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Safari or Firefox.

Option 2 — recommended for development:
From inside this folder run a local static server, for example:

Python:
  python -m http.server 8000

Then open:
  http://localhost:8000

FEATURES
--------
- Cinematic preload experience with automatic fallback
- Scroll progress and section index rail
- Reactive golden filament hero animation
- Mouse/parallax interaction
- Sticky brand-story sequence
- Horizontal scroll-driven manufacturing journey
- Animated manufacturing/thread field
- Interactive Zari Lab
  - S / Z twist selection
  - TPM control
  - Visual yarn-feel control
  - Metallic tone selector
  - Filament helix preview
  - Cone preview
- B2B / export enquiry section
- Responsive desktop/mobile layout
- Reduced-motion mode support
- No external CDN or font requirement

NOTES
-----
This is a standalone front-end concept. The business enquiry form currently
runs as a concept/demo and should be connected to the production CRM/API,
email workflow or backend before launch.

Public-facing technical, export, certification, capacity and contact claims
should be verified by SuvarnaTantu before production launch.
