Product overview

What is ST Type Metallic Yarn?

In ST Type, metallic flat yarn covers a textile-filament core. Polyester, rayon or viscose, and nylon are common core options; the core and film are selected for the required construction and end use.

Commercial ST constructions cover a wide range of core deniers and covering levels. Final choices are subject to technical review rather than a universal denier.

  • Core-supported metallic construction
  • Metallic film covering around a textile filament
  • Multiple construction and appearance options

ST Type FAQs

Questions buyers commonly ask

How do I select ST Type Metallic Yarn?

Start with the intended application, core preference if known, required metallic appearance and available construction context. The final ST Type specification is subject to technical review.

Can I request a ST Type sample?

Yes. Use the samples enquiry route and include the intended application and available requirement details.

Can the colour be discussed for ST Type?

Yes. Include the required colour or finish direction in the enquiry so it can be reviewed with the core and metallic-film construction.
