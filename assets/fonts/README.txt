SuvarnaTantu website font setup
================================

This project does not require any external font files.

The website uses local/system font stacks:
- Display / serif: Georgia, "Times New Roman", serif
- UI / body: Inter, Arial, Helvetica, sans-serif

If Inter is not installed on the viewing computer, the browser automatically
falls back to Arial/Helvetica. This keeps the ZIP fully offline-compatible and
avoids third-party font dependencies.
